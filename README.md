# 时空纪元 · 地理闯关 (Chrono Geo Quest)

以「宇宙演化时间线」为舞台的地理选择题闯关游戏。21 个时代阶梯，从石器时代一路攀爬到星光神域，答错即坠回上一个时代，坠出时间线尽头则宇宙坍缩。

## 在线游玩

- WorkBuddy 托管：<https://chrono-geo-quest.app.workbuddy.host/?sharecode=3W55XANLYR>
- GitHub Pages：见仓库右侧 About 链接

## 玩法规则

- 从**石器时代**出发，沿 21 个时代向未来攀爬，终点为**星光神域**
- 每个时代 5~10 题（越靠后的时代题量越多），每题限时 **120 秒**，超时算错
- **冷冻核心**：答错消耗一枚；核心耗尽即刻**坠回上一个时代**，题目重新随机
- 每通过一个时代获得一枚核心（上限 3 枚），即容错额度会随进度累积
- 每通过 2 个时代触发一次**时空穿越**：3 道高难题，全对连升两纪，错一题退回出发时代
- 坠出时间线最底端 → 宇宙坍缩（Game Over）；抵达星光神域 → **神格觉醒 · 时空主宰**

## 题库

263 道选择题，依据湘教版八年级地理上册期中知识清单（第 1-2 章：中国的疆域与人口、中国的地形与气候、河流与长江黄河）编写，覆盖：

- 疆域与位置（领土四至、陆上邻国、内海、海域）
- 34 个省级行政区（简称、行政中心、之最）
- 人口分布、民族构成与分布
- 地形地势、气候特征
- 河流水文、长江与黄河各河段特征

每题含题干、4 个选项、正确答案、**原文解析**（答错时展示）与三档难度标签（基础 / 辨析 / 综合）。选项顺序在构建时打乱。

## 目录结构

```
src/
  q1.json ... q6.json   题目分片（人工编写）
  questions.json        合并并打乱选项后的题库
  template.html         游戏单页模板（HTML + CSS + JS，含氛围粒子引擎）
build.py                构建脚本，把题库注入模板生成 dist/index.html
dist/index.html         构建产物（发布到 gh-pages）
```

## 本地构建

```bash
python3 build.py          # 生成 dist/index.html
open dist/index.html      # 直接浏览器打开即可玩
```

无依赖、无后端。进度仅存 `localStorage`。

## 技术说明

- 纯静态单页，零依赖零构建工具链（仅 Python 标准库）
- 氛围系统：每个时代有专属配色、天空渐变与粒子效果（熔岩火星、冰川落雪、孢子浮游、蒸汽烟雾、电光、字节雨、跃迁流光、神域极光）
- 音效由 Web Audio API 实时合成，无需音频资源文件
- 移动端优先布局，桌面端居中呈现
