# 时空纪元 · 知识闯关 (Chrono Geo Quest)

以「宇宙演化时间线」为舞台的多科目选择题闯关游戏。21 个时代阶梯，从石器时代一路攀爬到星光神域，答错即坠回上一个时代，坠出时间线尽头则宇宙坍缩。


## 玩法规则

- 从**石器时代**出发，沿 21 个时代向未来攀爬，终点为**星光神域**
- 每个时代 5~10 题（越靠后的时代题量越多），每题限时 **120 秒**，超时算错
- **冷冻核心**：答错消耗一枚；核心耗尽即刻**坠回上一个时代**，题目重新随机
- 每通过一个时代获得一枚核心（上限 3 枚），即容错额度会随进度累积
- 每通过 2 个时代触发一次**时空穿越**：3 道高考风格拔高题（难度档 4），每题限时只有常规的一半（**60 秒**），三题题型互不重复；全对连升两纪，错一题退回出发时代
- 坠出时间线最底端 → 宇宙坍缩（Game Over）；抵达星光神域 → **神格觉醒 · 时空主宰**
- 彩蛋：抵达星光神域的结算页后，试试**点击那枚金色的神格印记**
- 彩蛋：坠落到底的「宇宙收缩」页面，**点亮小宇航员手里那根火柴**——谷底没有更低的地方，之后的每一步都是高点

## 三重道途（周目）

周目**不由玩家选择**，而是每个科目各自随进度单向推进，不能手动切换：

> 未通关 → **时空纪元**；通关 → **修仙记**；再通关 → **无我篇**；入无我境 → 闭关 5 天 → **转世**回第一关（进入下一世）

- 每个科目独立记录自己的周目、境界与**世数**（地理可以在无我篇，历史还在时空纪元）
- 转世只清三周目的进度；**历代星碑全部保留**，墙上每块碑都带「第 N 世」标记
- 入无我境后该科目**闭关 5 天**不可进入（其他科目照常），倒计时以服务端时间为准，改本机时间无效

| | 时空纪元 | 修仙记 | 无我篇 |
|---|---|---|---|
| 起点第 9 级 | 石器时代 | 筑基初期 | 明心 |
| 终点 | 星光神域 | 道祖 | **无我境** |
| 每题限时 | 120s | 100s | 90s |
| 穿越关卡 | 时空裂缝 | 天劫 · 雷池 | 心魔劫 |
| 核心道具 | 冷冻核心 | 护道玉符 | 定心珠 |
| 主题色 | 深空蓝金 | 青蓝仙气 | 墨白留白 |

### 第二周目 · 修仙记

同一套玩法与题库，换成**修仙皮**：21 个时代 → 21 重境界（凡尘 → 淬体 → 炼气 → **筑基初期起步** → 金丹 → 元婴 → 渡劫 → 道祖）。术语全套替换：跃迁→**破境**、坠落→**跌境**、时空穿越→**天劫**、冷冻核心→**护道玉符**、神格觉醒→**飞升 · 道祖**、宇宙收缩→**道消身殒**。界面整体转为青蓝仙气配色，通关彩蛋神谕换为修仙版。

### 第三周目 · 无我篇

最高境界为**无我境**（沉沦 → 起念 → 执着 → 挣扎 → 省身 → 知苦 → 觉察 → 观照 → 破执 → **明心起步** → 见性 → 止观 → 静虑 → 澄心 → 忘机 → 忘形 → 忘言 → 空明 → 无住 → 无相 → 无我境）。

- 术语：破境→**悟道**、跌境→**退转**、天劫→**心魔劫**、护道玉符→**定心珠**、飞升→**入无我境**、道消→**沉沦**
- 界面去色留白：金色转月白，通关图与谷底图灰度化，越往上装饰越少
- 通关后不再是「再闯一次」，而是**闭关五日**——到了无我境，就不必急着再刷

## 题库

共 **1151 道选择题**，分四个科目（`src/data/<科目>-<序号>.json`），构建时按文件名前缀自动归科：

| 科目 | 题量 | 范围 |
|---|---|---|
| 地理 | 346 | 湘教版八年级上册第 1—2 章（疆域与人口、地形与气候、河流与长江黄河）+ 高考风格综合题 |
| 历史 | 288 | 部编版八年级上册第 1—12 课（中国近代史 1—4 单元）+ 史料实证与因果论证题 |
| 生物 | 178 | 八年级上册期中范围 + 实验探究与图表分析题 |
| 诗歌 | 339 | 中考范围 · 部编版初中必背古诗文 + 高考风格鉴赏比较题 |

每题含题干、4 个选项、正确答案、**原文解析**（答错时展示）与难度档标签（1 基础 / 2 辨析 / 3 综合 / 4 高考风格拔高，档 4 专供时空穿越）。选项顺序在构建时按题干哈希稳定打乱。

## 目录结构

```
src/
  data/                 题库分片，按 <科目>-<序号>.json 命名（geo/hist/bio/poem）
  subjects.json         科目配置（名称、图标、简介、主题色）
  questions.json        旧版合并题库（已由 data/ 分片取代，保留备份）
  template.html         游戏单页模板（HTML + CSS + JS，含氛围粒子引擎）
build.py                构建脚本：合并分片 → 打乱选项 → 注入模板，生成 dist/index.html
dist/index.html         构建产物（发布到 gh-pages）
```

## 本地构建

```bash
python3 build.py          # 生成 dist/index.html
open dist/index.html      # 直接浏览器打开即可玩
```

无依赖、无后端。进度仅存 `localStorage`。

## 技术说明

- 纯静态单页，零依赖零构建工具链（仅 Python 标准库）
- 氛围系统：每个时代有专属配色、天空渐变与粒子效果（熔岩火星、冰川落雪、孢子浮游、蒸汽烟雾、电光、字节雨、跃迁流光、神域极光）
- 音效由 Web Audio API 实时合成，无需音频资源文件
- 移动端优先布局，桌面端居中呈现
